# AIの判断と安全監視の表示

起動方法は [SETUP](SETUP.md#windowsのネイティブgui) を参照してください。
Windows標準のTkを使うネイティブウィンドウで、ブラウザーの履歴やブックマークを表示しません。
localhostの表示サーバーから、実際のROSトピックの情報を取得します。

1. ゴール配置を「標準ゴール」または「障害物の真裏」から選ぶ。
2. 「走行準備」を押す。Gazeboとカメラを整え、停止して開始を待つ。
3. 「開始待ち」になったら録画と画面配置を整える。待機に制限秒数はない。
4. 「走行開始」を押す。途中で終了するときは「停止」を押す。
5. 撮り直しは、終了後に再び「走行準備」から行う。

開始操作はセッション別の識別子と鮮度・センサー更新を確認して受け付けます。
古い開始操作を次の試行へ流用しません。アプリを閉じると、そのアプリが準備した走行へ停止要求を送ります。
GUIの開始・停止は車両の操作です。動画の録画は録画アプリで開始・終了します。
準備中のAI要求速度や推論時間の「—」は、制御器がまだ起動していないことを表します。

表示項目はAI/模範制御の要求速度、車両への速度指令、目標距離、推論時間、安全監視の理由、12方向の測距です。
更新が途絶えた値は隠します。速度表示は指令値であり、車輪から測定した実速度ではありません。
通常のAI走行と、姿勢を設定した別の安全停止試験を画面上でも区別します。

「障害物の真裏」のゴールは (3.8, 0.0) mで、初期位置から目印が遮られます。
現在は座標が既知の目標への移動であり、画像による未知の目標の探索機能はありません。
追加配置でAIが80秒未到達だった保存結果は [RESULTS](RESULTS.md) を参照してください。
