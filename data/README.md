# 模範走行の教師データとモデル

Gazebo内で模範制御器を実行して取得した8エピソード・3,007行のCSVです。
人物やカメラ画像は含まず、時刻・12方向の測距・既知の目標までの距離と方向・要求速度を記録しています。

同じエピソードの隣接行を学習と検証に混ぜず、学習1,966行と検証1,041行へ分割しました。
`models/training_metrics.json` に採用時の分割ID、seed42、誤差を保存しています。
正規化情報は `models/normalization.json`、採用重みは `models/navigation_policy.pt` です。
モデルはこのプロジェクトのローカルな模倣学習で作成したもので、外部の画像認識モデルではありません。

再学習は `python3 -m pai_ai_navigation.train --data data --output models_v2`。
既存のモデルを上書きしない仕様です。依存ライブラリや環境が変わると数値が変わる可能性があります。
同梱のモデルによる推論確認と、再学習したモデルの評価は区別してください。

新しいCSVは意図しない公開を避けるためGitから除外します。同梱の8ファイルだけを `.gitignore` で明示的に許可しています。
